# SberWise

Telegram-бот и Mini App для совместного бюджета: учитывайте расходы, делите чеки между участниками, следите за долгами и анализируйте траты в одной комнате.

## Что умеет

- Комнаты для совместных расходов и приглашения участников.
- Добавление расходов вручную, текстом, голосом, фото чека, PDF или CSV.
- Распределение расходов между выбранными участниками.
- Автоматический расчёт долгов и минимального числа переводов.
- Напоминания о долгах и настройка их частоты.
- История покупок, фильтры по категориям и аналитика расходов.
- Интерактивные donut-диаграммы и персональный баланс «вам должны / вы должны».
- AI-распознавание фото чеков, текстовых расходов, голосового ввода и советы по бюджету.
- Telegram Mini App с адаптацией под мобильные устройства.

## Стек

- Python 3.10+
- aiogram 3 — Telegram Bot API
- aiohttp — API и Mini App
- SQLite — хранение данных
- JavaScript / HTML / CSS — интерфейс Mini App
- OpenAI GPT-4o mini и Whisper — опциональные AI-функции

## Быстрый запуск

1. Склонируйте репозиторий и перейдите в папку проекта.

   ```bash
   git clone <YOUR_REPOSITORY_URL>
   cd SberWise
   ```

2. Создайте виртуальное окружение и установите зависимости.

   ```bash
   python -m venv .venv
   .venv\Scripts\activate
   python -m pip install -r requirements.txt
   ```

3. Создайте в корне файл `.env`. Он не должен попадать в Git.

   ```env
   BOT_TOKEN=your_telegram_bot_token
   OPENAI_API_KEY=
   GEMINI_API_KEY=
   WEBAPP_URL=
   PORT=8899
   DATABASE_PATH=expenses.db
   APP_VERSION=dev
   ```

   `OPENAI_API_KEY` и `GEMINI_API_KEY` необязательны. Без них приложение продолжит работать: для распознавания будут использоваться локальные fallback-механизмы там, где они доступны.

4. Запустите приложение.

   ```bash
   python bot.py
   ```

После запуска локальная версия Mini App доступна по адресу `http://127.0.0.1:8899/webapp`.

На Windows также можно использовать `start.bat`.

## OpenAI: что расходует API-бюджет

Токены OpenAI используются только при включённом `OPENAI_API_KEY`:

| Сценарий | Модель |
| --- | --- |
| Фото чека | GPT-4o mini Vision |
| Текстовый расход и PDF-нормализация | GPT-4o mini |
| Голосовой ввод | Whisper + GPT-4o mini |
| AI-советы, дайджесты и умные напоминания | GPT-4o mini |

Расчёты долгов, диаграммы, история, фильтры, обычные уведомления и интерфейс Mini App не расходуют OpenAI API-токены.

## Безопасность

- Никогда не публикуйте `BOT_TOKEN`, `OPENAI_API_KEY`, `GEMINI_API_KEY` или рабочий `.env`.
- Перед первым push проверьте `git status` и убедитесь, что секретные файлы не попали в индекс.
- Если ключ уже оказался в публичном репозитории, немедленно отзовите его в сервисе-провайдере и выпустите новый.
- Для production используйте переменные окружения хостинга, а не файлы с секретами в репозитории.
